# Лабораторна робота №1 — Комунальні показники

## Про роботу

Лабораторна робота №1 з дисципліни
«Кросплатформні засоби програмування».

Тема: «Розгортання Java-проєкту та базова обробка даних».

Варіант №9 — «Комунальні показники».

## Призначення програми

Консольна Java-програма читає дані про комунальні показники
з CSV-файла, перевіряє коректність записів, виконує обчислення
та формує текстовий звіт.

## Формат вхідних даних

Один запис розміщується в одному рядку.

Поля розділяються символом `;`.

Формат:

`meter;date;value;tariff`

де:

- `meter` — назва або ідентифікатор лічильника;
- `date` — дата у форматі `YYYY-MM-DD`;
- `value` — значення споживання;
- `tariff` — тариф.

Приклад коректного запису:

`Електролічильник-1;2026-09-01;125.50;4.32`

Вхідний файл зберігається у кодуванні UTF-8.

## Обчислювані показники

Програма визначає:

1. кількість коректних записів;
2. сумарне споживання;
3. загальну вартість;
4. найбільше споживання.
