# Лабораторна робота №1 — Комунальні показники

## Про роботу

Лабораторна робота №1 з дисципліни
«Кросплатформні засоби програмування».

Тема: «Розгортання Java-проєкту та базова обробка даних».

Варіант №9 — «Комунальні показники».

Проєкт реалізовано на Java 21.

---

## Призначення програми

Консольна Java-програма читає дані про комунальні показники
з CSV-файла, перевіряє коректність кожного запису,
виконує обчислення та формує текстовий звіт.

Некоректний рядок не завершує роботу всієї програми.
Для такого запису виводиться номер рядка та причина його пропуску.

---

## Формат вхідних даних

Один запис розміщується в одному рядку.

Поля розділяються символом `;`.

Формат:

`meter;date;value;tariff`

де:

- `meter` — назва або ідентифікатор лічильника;
- `date` — дата у форматі `YYYY-MM-DD`;
- `value` — значення споживання;
- `tariff` — тариф.

Приклад коректного запису:

`Електролічильник-1;2026-09-01;125.50;4.32`

Вхідний файл зберігається у кодуванні UTF-8.

За замовчуванням програма читає файл:

`data/input.csv`

---

## Перевірка вхідних даних

Для кожного запису програма перевіряє:

- чи рядок не порожній;
- чи запис містить рівно 4 поля;
- чи поле `meter` не порожнє;
- чи поле `date` не порожнє;
- чи `value` є числом;
- чи `tariff` є числом;
- чи `value` не є від’ємним;
- чи `tariff` не є від’ємним.

Для поділу рядка використовується:

`split(";", -1)`

Це дозволяє не втрачати порожні поля.

Числові значення перетворюються через `Double.parseDouble`.

---

## Обчислювані показники

Для всіх коректних записів програма визначає:

1. кількість коректних записів;
2. сумарне споживання;
3. загальну вартість;
4. найбільше споживання.

Загальна вартість визначається як сума:

`value * tariff`

для всіх коректних записів.

## Maven

Для керування проєктом використовується Maven.

У `pom.xml` налаштовано:

- Java 21;
- UTF-8;
- JUnit 5;
- SpotBugs;
- Maven Shade Plugin.

Для запуску Maven використовується Maven Wrapper,
тому користувачу проєкту не потрібно мати однакову
глобально встановлену версію Maven.

На Windows використовується:

```powershell
.\mvnw.cmd
```

На macOS або Linux:

```bash
./mvnw
```

---

## Компіляція

На Windows:

```powershell
.\mvnw.cmd compile
```

На macOS або Linux:

```bash
./mvnw compile
```

Після компіляції результати створюються в каталозі:

`target/`

---

## Автоматизовані тести

Для автоматизованого тестування використовується JUnit 5.

Запуск тестів на Windows:

```powershell
.\mvnw.cmd test
```

На macOS або Linux:

```bash
./mvnw test
```

Тести розташовані у файлі:

`src/test/java/ua/lpnu/kzp/MainTest.java`

Тестами перевіряються:

- коректні записи;
- нечислові значення;
- від’ємні значення;
- порожній рядок;
- порожнє обов’язкове поле;
- неправильна кількість полів;
- файл без жодного коректного запису;
- українські символи у UTF-8;
- правильність сформованого звіту.

Поточний результат:

```text
Tests run: 3, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

## Статичний аналіз

Для статичного аналізу використовується SpotBugs.

SpotBugs прив’язаний до фази Maven `verify`.

Запуск на Windows:

```powershell
.\mvnw.cmd verify
```

На macOS або Linux:

```bash

```

Під час `verify` також виконуються автоматизовані тести.

Поточний результат SpotBugs:

```text
BugInstance size is 0
Error size is 0
No errors/warnings found
BUILD SUCCESS
```

## Створення виконуваного JAR

Для пакування програми використовується Maven Shade Plugin.

У конфігурації вказано головний клас:

`ua.lpnu.kzp.Main`

```powershell
.\mvnw.cmd package
```

На macOS або Linux:

```bash
./mvnw package
```

`target/lab01-1.0.0.jar`

## Запуск програми

Звичайний запуск готового JAR:

```powershell
java -jar target\lab01-1.0.0.jar
```

За замовчуванням програма читає:

`data/input.csv`

і записує звіт у:

`out/report.txt`

## Довідка

Для перегляду доступних аргументів:

```powershell

```


## Використання власного вхідного файла

Для передавання іншого вхідного файла використовується аргумент `--input`.

Приклад:

```powershell
java -jar target\lab01-1.0.0.jar --input data\input.csv
```

---

## Використання власного вихідного файла

Для визначення шляху до звіту використовується аргумент `--output`.

Приклад:

```powershell
java -jar target\lab01-1.0.0.jar --output reports\result.txt
```

## Одночасне використання `--input` і `--output`

```powershell
java -jar target\lab01-1.0.0.jar --input data\input.csv --output reports\result.txt
```

## Приклад результату

Для тестового файла програма отримує:

```text
Результати:
Кількість коректних записів: 3
Сумарне споживання: 186.25
Загальна вартість: 1198.32
Найбільше споживання: 125.50
```

Звіт записується у кодуванні UTF-8.

Для форматування дробових чисел використовується `Locale.ROOT`,
тому десятковим роздільником залишається крапка незалежно
від локальних налаштувань операційної системи.
