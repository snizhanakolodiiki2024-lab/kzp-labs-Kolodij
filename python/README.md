## Формат вхідних даних

CSV-файл використовує кодування UTF-8 та заголовок:

```csv
meter,date,value,tariff
Електролічильник-1,2026-11-01,125.5,4.32
Водомір-1,2026-11-02,35.25,35.2
```

| Поле | Тип після завантаження | Призначення |
|---|---|---|
| meter | str | Назва лічильника |
| date | datetime.date | Дата показника |
| value | float | Значення споживання |
| tariff | float | Тариф |

Числові значення повинні бути невід'ємними та скінченними.
Дата повинна відповідати формату YYYY-MM-DD.

CSV підтримує текстові поля з комами, лапками
та перенесеннями рядків.

## Встановлення

Усі команди виконуються з каталогу python.

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

### Ubuntu та macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

## Запуск програми

```bash
python -m kzp_lab06.cli data/input.csv reports/summary.txt
```

Або через встановлений CLI-скрипт:

```bash
kzp-report data/input.csv reports/summary.txt
```

Запуск із власним порогом:

```bash
kzp-report data/input.csv reports/summary.txt --threshold 100
```

Довідка:

```bash
kzp-report --help
```

Типове значення threshold дорівнює 75.0.
Відбір виконується за строгою умовою value > threshold.

## Обробка помилок

Програма використовує власний виняток DataError.

Підтримується обробка:

- відсутнього файла;
- некоректного заголовка CSV;
- відсутнього або зайвого поля;
- некоректного числа;
- від'ємного значення;
- NaN та Infinity;
- некоректної дати;
- пошкодженого CSV;
- помилок файлової системи.

CSV лише із заголовком повертає порожній список.
Повністю порожній файл вважається некоректним.

Коди завершення CLI:

- 0 — успішне виконання;
- 2 — очікувана помилка даних, файла або аргументів.

Вхідний CSV не змінюється.
